# Схема правильной перелинковки: контент ↔ услуги

**Сайты:** decorativearchitecturalproducts.com (DP) · royalfoam.art (ART) · decorativearchitecturalshapes.com (DS)
**Дата:** 21 сентября 2026
**Полная построчная таблица (214 ссылок):** `interlink-scheme.csv` (разделитель `;`, колонки `id;site;source_title;source_url;target_title;target_url;anchor;placement;priority;notes`)
**Основание:** аудиты `interlink-audit-products.md`, `interlink-audit-art.md`, `interlink-audit-shapes.md` — пары «статья → услуга» уже проверены чтением каждой страницы.

## Логика схемы (5 правил)

1. **Каждая статья → своя услуга: 2 контекстные ссылки.** Первая — exact-match анкор в интро (первые 2 абзаца), вторая — partial-match в финальном CTA-блоке. Именно так уже сделано в единственном удачном месте группы (DS-пост про тримы) — масштабируем этот паттерн.
2. **Каждый кейс → своя услуга: ссылка в тексте + кликабельная CTA-кнопка.** Тексты кнопок унифицированы по услуге («Discuss your fence project», «Discuss your 3D logo project»…), интро-анкоры уникальны под каждый кейс.
3. **Каждая услуга → свой контент: 2 новых тематических блока.** «Related guides» (гайды) + «Related cases» (кейсы) вместо/в дополнение к виджету «3 последних» (DP, DS) и статичным «3 oldest» (ART). Анкор карточки = заголовок материала.
4. **Анкорная политика: 1 exact + N partial.** Точное название услуги — один раз (интро статьи), дальше — частичные вхождения и CTA-фразы. Одинаковых CTA-кнопок в пределах одной услуги — можно (это кнопки, не контентные ссылки).
5. **Всё двустороннее.** Каждая пара связана в обе стороны: статья/кейс → услуга и услуга → статья/кейс. Висячих («в одну сторону») связок после внедрения — ноль.

## Карта размещений (placement)

| Placement | Где | Что это |
|---|---|---|
| `body-intro` | Первые 1–2 абзаца статьи/кейса | Контекстная ссылка, exact-match анкор |
| `body-final-cta` | Финальный абзац/CTA-блок статьи | Контекстная ссылка, partial-match анкор |
| `case-cta-button` | Продуктовый подвал кейса («Discuss the project») | Кнопка → ссылка на услугу |
| `related-guides-block` | Новый блок на услуге | Карточки тематических статей |
| `related-cases-block` | Новый блок на услуге | Карточки тематических кейсов (сетка до 12) |
| `fix-existing` | ART-пост №4 | Заменить ошибочную ссылку на правильную цель |

## Очередность внедрения (волны)

- **Волна 0 — фиксы шаблонов (1–2 часа, до всего остального):** DP «See all services» → `/services/`; ART статичный блок 3-oldest → тематический/3-latest; DS убрать self-link из «Similar projects» + вернуть 2 выпавших кейса; ART-пост №4 — заменить ссылку (ART-007).
- **Волна 1 — P1 «контент → услуги» (131 ссылка):** все `body-intro`, `body-final-cta`, `case-cta-button` с приоритетом P1. Закрывает главную дыру аудитов.
- **Волна 2 — P1 «услуги → контент» (66 ссылок):** блоки «Related guides / Related cases» на 35 услугах (DP 13, ART 11, DS 11). Крупные сетки: ART oversize-letters (9 кейсов), DS fence-systems (12 кейсов), ART 3d-logo (4 кейса).
- **Волна 3 — P2 (17 ссылок):** вторичные связки + временные ссылки на хаб `/services/` для страниц без целевой услуги.

## Решения по страницам без целевой услуги

| Страница | Решение в схеме | Постоянный фикс |
|---|---|---|
| DP пост Trim/Molding, кейсы Signage/Shutters/Wall Panels | Временная ссылка на хаб `/services/` (DP-010, 025–027) | Создать услуги |
| DP кейсы Balusters/Balustrade | Строк нет — ждать публикации услуги из таблицы | Опубликовать услугу, затем 4 ссылки по шаблону кейса |
| DS пост Keystones, Shutters, Install-guide | Ближайшие соответствия: Arches / Louvers / Moldings (P1) | Опционально создать Keystones/Shutters |
| DP пост Porch Columns (404) | Строк нет — сначала восстановить или редирект | Восстановить + 2 ссылки по шаблону статьи |

## Автоматизация (вариант A — сниппет на лету)

Покрывает 98 ссылок с placement `body-intro` / `body-final-cta` (DP 32, ART 35, DS 31):

- `build-interlink-map.py` — генератор (CSV → JSON + сниппеты), запускать из корня репо;
- `interlink-map.json` — машиночитаемый маппинг (98 правил);
- `interlink-snippet-template.php` — общий шаблон сниппета;
- `interlink-snippet-dp.php`, `interlink-snippet-art.php`, `interlink-snippet-ds.php` — готовые файлы для вставки в WPCode (по одному на сайт), режим по умолчанию DRY-RUN (только лог, без изменений).

Не покрыты сниппетом (шаблоны/ручная работа): `case-cta-button` (48 кнопок через ACF-поле `related_service`), блоки `related-guides-block` / `related-cases-block` (72 ссылки), `fix-existing` ART-007 (1 ссылка вручную).

## Контроль качества после внедрения

1. Перепроверить выборку: по 1 статье, 1 кейсу, 1 услуге с каждого сайта — все ссылки из CSV на месте, анкоры точные.
2. Проверить, что не осталось ссылок на 404 и что временные hub-ссылки заменены после создания услуг.
3. При публикации каждой новой статьи/кейса — сразу 2 ссылки по правилам 1–2 + карточка на своей услуге (правило 3).
