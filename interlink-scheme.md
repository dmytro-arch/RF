# Схема правильной перелинковки: контент → услуги (только интро)

**Сайты:** decorativearchitecturalproducts.com (DP) · royalfoam.art (ART) · decorativearchitecturalshapes.com (DS)
**Дата:** 21 сентября 2026; **финальное решение 22 сентября 2026: только интро-ссылки**
**Исполнительная таблица (65 ссылок):** `interlink-scheme-c.csv` (разделитель `;`, все строки — placement `body-intro`)
**Бэклог (не исполнять):** `interlink-scheme.csv` (v1, 214 строк) + предыдущая версия `interlink-scheme-c.csv` на 137 строк (с Related-блоками) — в истории git
**Основание:** аудиты `interlink-audit-products.md`, `interlink-audit-art.md`, `interlink-audit-shapes.md` — пары «статья → услуга» уже проверены чтением каждой страницы.

## Решение: ровно одна ссылка в интро, больше ничего

Со страницы контента (статья/кейс) на свою услугу ведёт **ровно одна контекстная ссылка в интро** (exact-match анкор, первые 1–2 абзаца). Никаких вторых ссылок, CTA-кнопок и обратных блоков на услугах в этом заходе — чистый тест «одна ссылка закрывает дыру».

Исключены из исполнения (бэклог): `body-final-cta`, `case-cta-button`, `related-guides-block`, `related-cases-block`.

## Правила (2)

1. **Контент → услуга: ровно 1 контекстная ссылка в интро.** Exact-match анкор (название услуги) в первых 1–2 абзацах. Эталон — единственное удачное место группы (DS-пост про тримы: там ссылка уже есть, строка не требуется, не трогать).
2. **Связь односторонняя (по решению).** Обратные ссылки «услуга → контент» (Related-блоки) — в бэклоге, могут быть добавлены вторым заходом после замера эффекта.

## Автоматизация (сниппет на лету)

Покрывает все 65 ссылок (DP 16, ART 29, DS 20), все в режиме `replace`:

- `build-interlink-map.py interlink-scheme-c.csv` — генератор (CSV → JSON + сниппеты);
- `interlink-map.json` — машиночитаемый маппинг (65 правил);
- `interlink-snippet-template.php` — общий шаблон сниппета;
- `interlink-snippet-dp.php`, `interlink-snippet-art.php`, `interlink-snippet-ds.php` — готовые файлы для WPCode (по одному на сайт), режим по умолчанию DRY-RUN.

Вручную: только удаление ошибочной ссылки ART-007 (1 правка) + разбор NOT-FOUND из dry-run лога (ожидается <10%).

## Контроль качества

1. Выборка: по 1 статье и 1 кейсу с каждого сайта — ссылка в интро на месте, анкор точный.
2. Ни одна ссылка не ведёт на 404; ссылок не внутри других ссылок/кнопок.
3. Новые статьи/кейсы: сразу 1 интро-ссылка по правилу 1.
