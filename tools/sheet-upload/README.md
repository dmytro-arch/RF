# Свод ключевых фраз по трём сайтам

Итоговый файл: **`../../kw_results_merged.csv`** (875 строк + шапка).

## Что внутри

Одна строка = одна ключевая фраза одной страницы одного сайта.

| Колонка | Смысл |
|---|---|
| `Лист` | откуда строка: `shapes`, `royalfoam` или `products` |
| `Сайт` | домен |
| `Страница` | название страницы (услуги) |
| `URL` | адрес страницы |
| `Документ` | название связанного документа Google Docs |
| `Ссылка на документ` | ссылка на этот документ |
| `Слов в тексте` | объём текста страницы |
| `Ключевая фраза` | сам запрос |
| `Статус` | состояние проработки фразы |
| `Вхождений` | сколько раз фраза встречается в тексте |

Формат: UTF-8 с BOM, разделитель `;`, переводы строк CRLF — открывается в Excel
двойным щелчком, без мастера импорта.

## Как пересобрать

```bash
cd tools/sheet-upload
python3 expand_manual.py                    # manual/part1.tsv -> received/part1.csv
python3 merge.py ../../kw_results_merged.csv
```

`merge.py` понимает входные файлы в форматах `.csv`, `.tsv`, `.xlsx` и HTML-рендер
gviz, убирает полные дубликаты. Повторный прогон безопасен: файлы с теми же
данными дают побайтово тот же результат. Дедупликация идёт по всем девяти
колонкам исходных листов; `Лист` в ключ не входит, но коллизий быть не может —
каждому листу соответствует свой сайт.

Если таблица-исходник обновится, можно не читать её постранично, а загрузить
файлом: `server.py` поднимает приёмную страницу на порту 8000, куда `.xlsx`
или `.csv` кладутся в `received/` и подхватываются тем же `merge.py`.

## На что обратить внимание в исходных данных

- **Все 875 строк имеют статус «Не использован» и 0 вхождений.** Если часть
  запросов уже отработана, значит, эти данные не попали в публичный рендер.
- **4 фразы продвигаются сразу двумя сайтами** — `6x6 faux stone column wrap`,
  `faux stone column wraps 12x12`, `faux stone column wraps 6x6`,
  `how to install faux stone column wraps`. Страница-конкурент у shapes —
  *Faux Stone Decorative Facade Panels*, у products — *Faux Stone Column Wraps*.
  При сведении они намеренно оставлены разными строками: это разные сайты
  с разными URL.
- **Вероятная ошибка в исходнике:** на странице *Custom Stucco Wall Fence Systems*
  семь фраз посвящены акустическим панелям (`acoustic wall panels for living room`,
  `best acoustic wall panels`, `modern acoustic wall panels`, `foam acoustic wall panels`,
  `acoustic wall panels installation`, `acoustic wall panels bedroom`,
  `modular acoustic wall panels`).
- Названия страниц *Custom Capitals and Bases* и *Architectural Columns kits*
  встречаются в двух листах, но это разные страницы разных сайтов с разными URL.
