# QA royalfoam.art — автоматическая проверка

Функциональный аудит сайта: битые ссылки, редиректы, кнопки «в никуда», ошибки в консоли,
«поехавшая» вёрстка, состав и отправка форм, картинки без `alt`, время загрузки.

## Требования

- **Node.js 18+** (лучше 20 или 22) — проверить: `node -v`
- Для браузерного режима — Chromium, ставится одной командой (см. ниже).
- Для `--no-browser` и для тестов зависимости вообще не нужны.

## Установка и запуск

```bash
cd qa
npm install                        # ставит playwright (без браузера)
npx playwright install chromium    # добирает сам Chromium

npm test                           # юнит-проверки парсеров — без сети и браузера
npm run audit                      # 25 страниц, браузерный режим
npm run audit:full                 # до 200 страниц
npm run audit:form                 # заполнить и отправить форму на /contact/
node audit.mjs --no-browser        # только HTTP: ссылки, статусы, alt (Chromium не нужен)

node summarize.mjs out/full.json   # разбор готового отчёта БЕЗ повторного обхода
```

### Если отчёт огромный

На большом сайте одна и та же ссылка встречается на каждой странице, поэтому счётчики в конце
прогона выглядят страшно (например «редиректов 6341»). Это записи, а не уникальные проблемы.
`summarize.mjs` схлопывает дубли и раскладывает всё по полкам — сайт заново не обходится:

```bash
node summarize.mjs out/full.json --top 30
```

Он покажет: уникальные битые ссылки, редиректы по шаблонам (`/service/*` → `/services/*`),
кнопки «в никуда», уникальные ошибки консоли со счётчиком повторов, случаи горизонтального
скролла, уникальные конфигурации форм и самые медленные страницы. Результат — в
`out/full.summary.md`.

Windows (PowerShell) — те же команды, только `cd qa` и `npm install`;
если `npx` не найден, переустановите Node.js с nodejs.org (галочка «Add to PATH»).

## Параметры

| Параметр | Значение по умолчанию | Что делает |
| --- | --- | --- |
| `--site` | `https://royalfoam.art/` | с какой страницы начинать обход |
| `--max-pages` | `25` | сколько страниц обойти |
| `--out` | `out/report.json` | куда положить отчёт (рядом ляжет `.md`) |
| `--concurrency` | `4` | сколько страниц открывать параллельно |
| `--no-browser` | — | режим без Chromium (быстрее, но без консоли/вёрстки) |
| `--submit-form` | — | реально отправить форму на `/contact/` (только в браузерном режиме) |

Пример: `node audit.mjs --site https://royalfoam.art/ --max-pages 200 --out out/full.json`

## Что проверяется

| Проверка | Браузерный режим | `--no-browser` |
| --- | --- | --- |
| Статус каждой внутренней ссылки (404/5xx) | ✔ (`maxRedirects: 0`, видно 301) | ✔ (по конечному URL) |
| Редиректы и кнопки «в никуда» | ✔ (ссылки в меню отсекаются) | ✔ (само-ссылки помечаются как info) |
| Ошибки JS: `console.error`, `pageerror`, упавшие запросы | ✔ | — |
| Горизонтальный скролл на 1440/1024/768/390 px | ✔ | — |
| Формы: поля, подпись/placeholder, отправка | ✔ | состав полей |
| Картинки без `alt` | ✔ | ✔ |
| Время загрузки страницы | ✔ | ✔ |

Скрипт завершается кодом `1`, если нашлась битая ссылка, ошибка консоли или горизонтальный
скролл — удобно вешать в CI.

## Результаты

- `out/report.json` — машина-читаемый отчёт (`pages`, `links`, `consoleErrors`, `overflow`, `forms`, `timings`).
- `out/report.md` — то же самое в виде текста, удобно вставлять в тикеты.
- Папка `out/` в git не коммитится.

## Файлы

- `audit.mjs` — сам прогон (краулер + проверки).
- `lib.mjs` — чистые функции: разбор ссылок/картинок/форм, классификация статусов, генерация отчёта.
- `selftest.mjs` + `fixtures/sample.html` — проверки `lib.mjs`, работают офлайн.

## Если что-то не так

- `Cannot find module 'playwright'` → не выполнен `npm install` в папке `qa`.
- `Executable doesn't exist … chromium` → не выполнен `npx playwright install chromium`.
- Сайт отвечает 403/503 → Cloudflare может резать частые запросы; уменьшите `--concurrency 1`
  и добавьте паузу, либо прогоняйте с обычного рабочего компьютера.
- `--submit-form` создаёт реальную заявку в почте/CRM — используйте тестовый адрес.
